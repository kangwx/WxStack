# 奶油主题 · 标准 / 明亮

当前画面保留为标准版，默认使用标准。设置 → 画面风格，可在标准和明亮之间切换；点击、方向键与确认键均可操作，七个设置按钮在横竖屏中完整布局。

明亮版提亮八色方块、托盘表面、托盘粉色侧面、底座和周围装饰积木，保留倒角与立体明暗。背景和菜单继续沿用当前奶油配色。材质原位更新，已叠方块、碎块池及透明过渡保持一致，不改变碰撞、镜头或游戏进度。

选择保存到 `wxstack-cream-appearance-v1`，刷新后生效。不存在或无效的设置回退标准；存储不可用时仍可在本次会话切换。旧主题键仍清理且不参与配色，金币、体力、成绩、昵称等存档不受影响。

验证结果：86 项相关材质、存档、导航、布局和资源测试通过，TypeScript 检查和 Web Mobile 构建通过。全量回归 288 项中 275 项通过，13 项为此前已有的 UI 测试失败，没有新增失败。

## 明亮版第二次提亮

根据积木与托盘区域偏暗的反馈，明亮材质的线性亮度从 1.5 提高到 2.3，重点抬升侧面阴影和托盘表面，保留八色、倒角以及标准版原有材质。首页及设置截图、两版对比稿已同步更新。8 项外观与存档测试、TypeScript 检查和构建通过，浏览器无错误。
