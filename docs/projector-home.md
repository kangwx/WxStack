# 投影首页设计与验证

## 布局与交互

- 横屏首页采用左侧操作面板、右侧积木展示。独立断点为宽高比 1.2，覆盖 4:3 与 16:9 投影；超宽屏限制主要操作区跨度，避免视线过度分散。
- 主标题加粗放大；最高纪录和金币集中为两张信息卡，数字与说明分层。首页不再混排测试开关。
- 开始游戏、排行榜、设置保持居中单列。按钮背景、文字、实际点击区域与焦点框共享同一套布局尺寸。
- 焦点使用高对比填充、外圈和箭头，既有遥控器方向键、确认键、返回键逻辑保留。背景与统计卡不再触发开始游戏。
- “完美测试”移至设置，位于减少动态效果之后、返回首页之前；四项设置按连续焦点顺序导航。
- 首页展示镜头距离扩大至原来的 1.18 倍；横屏构图向右留出塔体区域。进入游戏时恢复原游戏镜头，不调整积木、物理、速度、计分或排行榜规则。
- 主题背景、260ms 整组轻滑动和减少动态效果支持保留。竖屏以完整菜单为优先，不要求背景塔体绕开中央面板。

## 检查结果（2026-09-11）

```sh
node /Applications/Cocos/Creator/3.8.8/CocosCreator.app/Contents/Resources/app.asar.unpacked/node_modules/typescript/bin/tsc -p tsconfig.json --pretty false --skipLibCheck true
node --test tools/test-home-layout.cjs tools/test-world-3d.cjs tools/test-remote-input.cjs tools/test-leaderboard.cjs
```

- 类型检查与 65 项测试通过，Web Mobile 构建成功；静态预览服务端口为 7460。
- 新增自动检查覆盖 1920×1080、1280×720、1024×768、390×844、3840×2160、2560×1080 的几何安全区、控件间距、焦点范围、按钮点击区域与字号；六主题的首页文字及焦点对比度；设置导航顺序和首页背景点击隔离；首页镜头与游戏镜头恢复。
- 浏览器实际查看 1920×1080 首页与设置、1024×768 首页、390×844 首页；文字与控件未见重叠，4:3 与 16:9 首页塔体完整可见，设置的四项导航可返回首页。
- 自动测试使用 Cocos 替身，几何及对比度断言不等于所有主题的逐帧 GPU 视觉验收。
- 尚未连接 Android WebView 或投影实机，实际投影亮度、遥控器硬件与 WebView 性能仍需设备验证。
