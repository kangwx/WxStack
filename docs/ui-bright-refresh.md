# 明亮奶油 UI 更新

保留奶油积木主题、圆角卡片和原有横竖屏布局。背景使用 #FFF3E2，面板 #FFFEF8，主按钮 #ABE9CF，次按钮 #FFE1DE，正文继续使用深色以保持可读性。

首页用暖黄色闪电图片代表体力，配合当前数量及自然恢复倒计时。5 点以内显示“当前值/5”，超过 5 点只显示实际数量；体力规则和广告奖励不变。

体力图片为本地 PNG SpriteFrame，随 UI 资源加载，不请求远程图片。HomeScreen、GameUIRoot 和 Stack 场景内嵌 UI 均包含图片节点及类型绑定。

本次对现有预制体作增量修改，保留 Editor 修改；生成器预检仍会保护之前已有的文件差异，没有重置生成清单。生成器中同步保留了图标的 SVG 绘制源和绑定定义，供后续合并编辑器改动时使用。

### 首页体力图标（2026-09-15）

首页体力区显示居中的五枚闪电及右侧数字：五点以内显示当前值/5，六至十点显示当前值/10，超过十点显示实际余额；不显示倒计时和加号入口。已有体力对应亮起图标，未拥有的体力以不透明灰色图标显示；余额超过五点仍只亮起五枚，展示上限不修改存档余额。补充体力沿用设置与体力不足时的广告入口。

验证：TypeScript 检查通过，体力与投影布局测试共 56 项通过，web-mobile 构建成功。
