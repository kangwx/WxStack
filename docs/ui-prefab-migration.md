## 开发命令

```sh
node tools/ui-baseline.cjs
node --test tools/test-ui-prefab.cjs
```

原语与按钮资源可用 `node tools/generate-ui-controls.cjs` 重建，需要正常安装的 `sharp`。
也可通过 `UI_SHARP_MODULE` 指定其模块目录；不要使用 Creator 内部仅适用于 Electron 的部分依赖。
该命令会重新生成上述按钮预制体和原语资源，**会覆盖这些生成文件中的手工修改**；不会修改场景或其他页面。
需要保留编辑器手工修改时，不要运行重建命令。后续完成迁移时应明确区分生成资源与人工维护的页面资源。

本轮按照 game-ui-ux 技能保留尺寸适配、焦点与减少动态效果合同，没有借迁移更改当前布局或页面状态机。
