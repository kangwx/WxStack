# 游戏、设置与排行榜的大屏统一设计

沿用新版首页的不透明奶油面板、加粗大标题、单列圆角按钮、焦点外圈与箭头，不改变游戏速度、金币奖励、排行榜存储或排序规则。

## 界面调整

- 游戏 HUD：放大当前分数与最高分，使用不透明高对比信息卡；暂停按钮独立放在右上安全区，竖屏时三项自动收窄且不重叠。
- 追分提示：两张信息卡下方间隔 20 个设计单位放置高度 44 的单行提示条，覆盖两卡及间距，沿用奶油面板底色与高对比说明文字；长文案自动缩小，不增加闪烁或弹窗。
- 设置：大标题与宽按钮；游戏音效、减少动态效果、完美测试的开关状态单独放在右侧，使用文字标记，不只依赖颜色。
- 昵称：设置增加“修改昵称”与当前昵称；独立居中输入面板支持保存、取消与文字输入焦点隔离。画布及其 UI 相机随可见尺寸居中，让原生输入区域与绘制边框一致。
- 排行榜：本机 Top 10 使用连续滚动列表，移除翻页与底部操作按钮。标题与列头固定，分数独立放大，前三名用金银铜数字徽章区分，本局保留边框与文字说明。支持上下键、手柄、触摸拖动和滚轮；右上角“×”或返回/确认键关闭。未知的旧纪录信息不补造数据。
- 暂停与结算：使用同一面板宽度、标题和按钮系统；暂停时隐藏底层 HUD，继续时恢复；结算显示大分数、最高分与本局奖励，测试模式说明保持单行。
- 横向面板沿用首页宽高比 1.2 的断点，适配 4:3 / 16:9；设置、暂停和结算保留左侧布局，排行榜从右侧展开到屏幕中央、占横屏宽度一半。暂停和失败的全景镜头为右侧积木留空间，继续游戏恢复原构图。

## 实现

- `assets/scripts/ProjectorLayout.ts` 计算纯设计空间布局；面板、字体、绘图尺寸、点击矩形和焦点外圈共用该几何结果。
- `StackGame.applyProjectorLayout()` 在尺寸变化时应用布局；HUD 数值仍由计分事件更新。
- 每局开始冻结当时的最高分作为追分目标，通过 `setScore()` 更新差值。未追平时显示“距最高还差 N 层”，追平时显示“已追平 · 再叠 1 层破纪录”，超出时显示“已超过最高 N 层”；没有历史纪录时分别显示“创造你的首个纪录”或“首个纪录：N 层”。最高分仍在正常结算时保存，下一局使用新纪录。
- 追分提示属于游戏 HUD，暂停时随 HUD 隐藏，继续后恢复；测试模式只显示原有“测试中”标识，不显示追分提示。
- 焦点复用首页的实色按钮、对比文字、外圈和箭头，不再附加第二层 TV 缩放。
- 保留背景常驻过渡、减少动态效果、确认键防连按与返回键导航。
- `StackWorld3D` 的背景铺满随镜头和视口立即刷新，不依赖游戏 tick；暂停时旋转屏幕也不会留下灰边，且不推进物理、碎片或粒子。
