# 本地排行榜与线上接入

首页现在是「开始游戏 → 排行榜 → 设置」。皮肤商店入口及快捷入口已关闭，已选主题、已兑换皮肤和金币数据保留。

首页右侧另有小排行榜，横屏预览前三名，竖屏紧凑展示第一名。按右键 / D / K、手柄向右，或者点击预览/排行榜按钮，会从右侧展开完整排行。展开后面板居中，横屏宽度为屏幕的一半；手机竖屏保留安全区内的可读宽度。返回时向右收起并恢复排行榜按钮焦点；减少动态效果时不滑动。

排行榜展示本机同一来源地址下的 Top 10 局成绩，十条连续放入可滚动列表。按层数降序、完美次数降序、完成时间升序排列，同分仍保留不同局记录。正常结算时提交一次；测试局和中途重开/退出的局不提交。已有最高分仅首次迁移为「历史最高」，不伪造时间和完美次数。

Web 版保存在 localStorage 的 `wxstack-leaderboard-v1`，格式为 `{ version: 1, entries: [...] }`。清除网页数据会清除排行；localhost、局域网 IP、不同端口以及不同浏览器/WebView 的存储各自独立。存储被拒绝时使用会话内排行，页面会提示无法跨会话保留。

展开后的操作：上下方向键、遥控器或手柄直接滚动列表；左右方向保留同样的前后滚动快捷操作。支持触摸/鼠标拖动、鼠标滚轮和惯性滚动，不再提供翻页或底部操作按钮。返回键、确认键或右上角“×”关闭榜单；再次打开回到列表顶部。减少动态效果时关闭惯性和按键滚动动画。

大屏使用完整面板内宽，固定标题和列头，昵称、段位与大号分数分区排列；前三名为金银铜数字徽章，本局仍保留文字和边框标记。右侧细滚动条显示位置，内容裁剪在列表视口内，首尾不越界；手机将昵称扩展为独立整行以容纳长名称。缩放屏幕时保留有效滚动位置，空榜、加载和错误状态仍有明确说明。

2026-09-13 按确认的设计图更新：排行榜使用独立的深青渐变面板、双层细描边与柔和阴影，卡片呈青色渐变，段位使用金色文字，前三名换成皇冠与双环圆形金银铜奖牌，关闭入口为薄荷绿线形叉号，滚动条同步使用薄荷绿。背景仍为实时游戏 3D 场景，不替换成静态设计图；其他界面及皮肤不受影响。界面绘图采用可缩放几何，不引入位图依赖。

## 昵称与称号

“设置 → 修改昵称”支持输入 1–12 个 Unicode 字符，默认昵称为“叠叠玩家”。输入会清理不可见控制字符、合并空白；空昵称或过长昵称不能保存。可点击保存/取消，用 Tab 切换焦点，Esc 取消；输入框的完成键先选中保存按钮，避免误提交。手柄可依次选择输入、保存、取消。

昵称单独保存在本机 `wxstack-nickname`，不会上传。存储不可用时本次会话仍生效，页面会明确提示。每局开始保存当时的昵称，结算后写入该局成绩；改名不回写旧成绩。旧 v1 成绩继续可读，没有昵称时显示“本地玩家”，不补造归属。

每条成绩展示昵称、层数与称号、原有日期及完美次数，称号按该局层数自动计算，不影响排序：

| 层数 | 称号 |
|---|---|
| 0–49 | 青铜 |
| 50–99 | 白银 |
| 100–199 | 黄金 |
| 200–349 | 铂金 |
| 350–499 | 钻石 |
| 500–599 | 最强王者 |
| 600–699 | 王者 +1 星 |
| 700–799 | 王者 +2 星 |

500 层之后每增加 100 层加一星，星数为 `floor((层数 - 500) / 100)`，不设额外星数上限。例如 1000 层为“王者 +5 星”，10000 层为“王者 +95 星”。称号即时从成绩计算，无需修改已有存档。

横屏首页的小排行榜也显示昵称和称号；手机紧凑预览保留名次和层数，展开后查看完整信息。

## 后续线上数据

`assets/scripts/Leaderboard.ts` 中的 `LeaderboardRepository` 提供异步 `list()` 和 `submit(result)`，界面不直接访问存储。接入线上时，实现此接口并替换 `StackGame.onLoad()` 中的实例化即可。当前没有任何网络上传。

- `RoundResult`：本局唯一 id、层数、完美次数、完成时间、测试标记和可选昵称快照。
- `LeaderboardEntry`：展示记录及可选昵称；历史导入项的时间/完美次数为 null，旧数据无昵称仍有效。
- `LeaderboardSnapshot`：排行数据及持久化状态。线上适配器需返回已经验证、排序的条目；如改为玩家总榜，可扩展昵称和分页字段。
- `submit` 应使用本局 id 做幂等处理；线上服务应验证分数、玩家身份和测试资格，不能把客户端分数视为可信依据。
- 界面已有加载、空榜、失败、存储降级状态；关闭页面会忽略迟到的加载响应。

验证：`node --test tools/test-home-layout.cjs tools/test-projector-layout.cjs tools/test-world-3d.cjs tools/test-remote-input.cjs tools/test-leaderboard.cjs`，共 165 项通过；TypeScript 检查和 Cocos web-mobile 构建通过。

浏览器已检查 390×844 手机、1280×720 和 1920×1080 横屏：输入框位置、中文与字母/空格/退格输入、两步确认、取消、重新加载后保留昵称，以及正常结算后的昵称和称号展示。输入法组合事件、遥控桥接、手柄导航和六套主题覆盖自动化回归；Android 原生输入法与实体遥控器/手柄仍需实机验收。
